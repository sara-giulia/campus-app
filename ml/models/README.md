# Trained ML.NET models

This folder holds the trained ML.NET models used by the CampusMarket API:

- `price-regression.zip` - predicts the asking price of a listing (B3).
- `category-classification.zip` - predicts the category of a listing (B4).
- `spam-detection.zip` - flags a listing as spam (B5).

The `.zip` files are committed so the API works out of the box without training
anything. The API loads them through `PredictionEnginePool` on startup.

## Retraining

From the repository root:

```
dotnet run --project ml/CampusMarket.ML.Training
```

The training project reads `ml/data/listings.csv` (generated by
`ml/CampusMarket.ML.DatasetGenerator`), splits it 80 / 20, runs every registered
trainer and writes the resulting model back into this folder.
